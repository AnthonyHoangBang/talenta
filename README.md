# Talenta · Nén Bạc (bản dùng thử)

Sổ tay đầu tư cá nhân: sổ giao dịch, danh mục, luận điểm cho từng lệnh mua, nhật ký, trang hồ sơ từng mã, tài sản khác và tổng kết lệnh đã đóng.

## Dùng thử trực tuyến
https://anthonyhoangbang.github.io/talenta/

## Cách mở trên máy
- Nhấp đúp vào `index.html`, trang sẽ mở trong trình duyệt. Không cần cài đặt gì.
- Muốn người khác mở được bằng link: đưa `index.html` lên một repo GitHub công khai rồi bật GitHub Pages (giống trang An Yên).

## Lưu ý
- Giá cổ phiếu, VN-Index và chỉ số doanh nghiệp là **số liệu mô phỏng**, chỉ có 8 mã: FPT, HPG, VCB, MWG, REE, TCB, DGC, VNM.
- Dữ liệu bạn nhập chỉ nằm trong trình duyệt đang dùng. Dùng nút "Sao lưu / khôi phục" ở cuối trang để cất dữ liệu.
- Hai tài khoản mẫu: SSI và VNDIRECT. Phí mua bán 0,15%, thuế bán 0,1%.
- App ghi chép và phân tích dữ liệu của chính bạn, không đưa ra khuyến nghị mua bán.
